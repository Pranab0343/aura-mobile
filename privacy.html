Aura Mobile Privacy Policy

Last updated: October 11, 2026

1. Introduction

Aura Mobile is an Android voice assistant that helps users interact with supported applications and services through voice commands. This policy explains how Aura Mobile handles personal information and Google user data.

2. Google Account Authorization

Aura Mobile uses Google OAuth 2.0 to request permission to access supported Gmail features. Users must authorize access through Google's consent process.

Aura Mobile requests access only to the Google account functionality needed for its Gmail integration.

3. Gmail Data Access and Use

With user authorization, Aura Mobile may access Gmail messages and related information to display, search, compose, reply to, and send emails at the user's request.

Gmail message content is processed locally on the user's Android device for these supported functions.

4. Data Sharing

Aura Mobile does not sell Gmail data. Gmail message content is not sent to Aura Mobile's Render backend for AI processing.

Information is transmitted to Google services as necessary to perform authorized Gmail operations, such as retrieving or sending messages.

5. Data Storage and Security

Aura Mobile aims to minimize storage of Gmail information and uses Google authorization mechanisms for account access. Users should protect their devices with appropriate security settings.

6. User Control and Revocation

Users can revoke Aura Mobile's access to their Google account through their Google Account security settings.

Revoking authorization prevents further authorized Gmail API access using that grant. Users may contact the developer to request information about deletion of any data retained by Aura Mobile.

7. Google API Services

Aura Mobile's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.
